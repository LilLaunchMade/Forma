# Changelog

## 1.0.0 — initial release candidate

- Independent offline Electron design studio for Windows x64.
- Interactive canvas, synchronized layers, text effects, shapes, image adjustments and nondestructive masks.
- Bundled local ONNX background removal with telemetry-free WASM CPU and optional WebGPU, plus erase/restore refinement.
- Twenty-four original templates across twelve categories, local custom templates and multipage designs.
- Embedded-asset `.forma` files, recovery autosave, local project library and font imports.
- PNG, JPG, SVG, multipage PDF and selected-page ZIP exports; dark/light themes and original branding.
- Windows installer and portable packaging; locked dependency builds, automated tests and tag-release workflow.

Release verification and limitations are tracked in `docs/RELEASE_READINESS.md` and `PROGRESS.md`. This entry is not evidence of a published GitHub release.
