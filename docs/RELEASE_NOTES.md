Forma 1.0.0 — Create without limits.

An independent Windows design studio with editable templates, typography, layers, image adjustments, multipage projects, local `.forma` files and PNG/JPG/SVG/PDF exports. Bundled ONNX background removal runs on your computer with CPU fallback and manual mask refinement. No accounts, subscriptions, API keys or runtime internet requirement.

Use `Forma-Setup-1.0.0.exe` to install or `Forma-Portable-1.0.0.exe` from a writable folder. Portable settings and recovery data live in `FormaData` beside the executable. Check downloads against `SHA256SUMS.txt`.

Windows 10/11 x64. These community builds are unsigned and can trigger SmartScreen. Read `docs/KNOWN_LIMITATIONS.md` and release-readiness evidence before deploying widely. PDF pages are rasterized; the compact AI model may require manual refinement on fine details. Original Forma code/templates/brand: MIT; bundled dependencies retain their licenses.
